# My Game Launcher

一个面向 Windows 的本地游戏启动器。选择游戏目录中的 `.exe` 导入后，可以在统一的游戏库里管理、启动和统计游玩时长。

## 已实现功能

- 选择 `.exe` 导入游戏，自动设置工作目录
- 编辑游戏名称、分类和启动参数
- 启动 / 停止游戏，检测文件是否存在
- 按游戏进程实际运行时间累计游玩时长
- 最近启动、收藏、搜索和多种排序方式
- 从 Steam 搜索封面并下载到本地缓存，也支持选择本地图片
- 删除游戏记录但不会删除原游戏文件
- 记住窗口大小，所有游戏库数据保存在本机
- 左下角设置：深色 / 浅色 / 跟随系统主题
- 重新扫描路径、移除失效记录、导入 / 导出 JSON 游戏库备份
- 删除按钮悬停显示“删除游戏”提示
- 右键点击游戏卡片可移出游戏库、编辑游戏或打开所在文件夹

## 开发

```powershell
npm install
npm start
```

## 打包

```powershell
npm run dist
```

安装器会输出到工作区的 `outputs` 目录。
